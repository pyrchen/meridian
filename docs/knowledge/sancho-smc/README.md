# База знаний: Smart Money по каналу @SanchoDT

Полная выгрузка и разбор русскоязычного курса по Smart Money Concepts —
51 ролик, 13.6 часа, июнь 2021 — апрель 2026.

## Что здесь лежит

| Каталог | Что это |
|---|---|
| `BOOK-part1.md`, `BOOK-part2.md` | **Справочник по главам 1–13.** Основной документ для чтения. |
| `extracted/` | Структурные извлечения по темам (A–J): определения, правила входа/стопа/цели, параметры, оценка формализуемости, ссылки на таймкоды. Промежуточный слой между транскриптами и справочником. |
| `transcripts/` | 51 транскрипт с YAML-шапкой и таймкодами `[MM:SS]`. Первоисточник для проверки любой цитаты. |
| `manifest.json` | Опись: id роликов, даты, длительности, объём в словах. |
| `ingest/` | Скрипты повторной выгрузки — догрузят только новые ролики при пополнении канала. |

## Как читать ссылки

Каждое утверждение снабжено ссылкой вида `файл.md [12:34]` — имя транскрипта и таймкод.
Таймкод соответствует времени в исходном ролике, ссылку на который найдёте в шапке
транскрипта.

**Ссылки проверены машинно.** В справочнике 422 ссылки (91 в части 1, 331 в части 2) —
все разрешаются в существующие транскрипты через таблицы алиасов, и каждый таймкод
подтверждён присутствием в тексте. В `extracted/` — 192 ссылки, из них 191 подтверждена
сразу, одно расхождение (`[04:35]` вместо фактического `[04:36]`) исправлено.

Иначе говоря, цитаты не выдуманы: любую можно открыть и сверить с видео.

Одно исключение стоит знать: извлечение `extracted/I-entries-management.md` (входы,
управление сделкой, риск) единственное из десяти вышло **без таймкодов вообще**. Ссылки
для главы 11 справочника выведены заново, прямым чтением всех четырёх исходных
транскриптов. Сама глава поэтому проверяема, а вот извлечение `I` — нет; если работаете
с ним напрямую, сверяйтесь с главой 11 или с транскриптами.

## Оговорки, которые важнее самого содержания

**Часть правил автор не формализует.** Он прямо говорит, что размечает свинг-точки
«визуально, не считая свечей», а в разных роликах даёт три несовпадающих определения слома
структуры. Понятия «значимый уровень», «сильная зона», «агрессивное движение» нигде не имеют
числового порога. В справочнике такие места помечены явно — по ним нельзя написать код,
не приняв собственное решение за автора.

**Курс эволюционировал.** Ролики 2021–2022 годов и их ремейки 2025–2026 годов местами
расходятся по методике. Где расхождение существенно, в справочнике указаны обе версии
с датами. Современная версия обычно строже и формализованнее.

**Качество распознавания неравномерно.** 14 роликов (ноябрь 2022 и всё с мая 2025) имеют
субтитры с пунктуацией; 37 более ранних — сплошной поток без знаков препинания. В извлечениях
из вторых числа, разобранные неуверенно, помечены `не уверен` вместе с дословной цитатой.
Такие числа нельзя использовать как параметры, не сверившись с видео.

Перераспознавание этих 37 роликов через Whisper было запущено локально на GPU, но
не завершилось: загрузка весов модели с Hugging Face с этой сети обрывается. Аудио
выгружено и лежит готовым — при восстановлении доступа перезапуск займёт около часа.

## Ограничение метода

Это разбор одного курса, а не проверенная торговая система. Автор не приводит статистики
своих сделок; заявленные им ориентиры (R:R 1:3, винрейт ~40%, минимум +3R на сетап) —
декларации, не измеренные результаты. Проверка этих идей на истории — предмет
`docs/SMC_ENGINE_SPEC.md` и бэктест-харнеса, а не этого документа.
